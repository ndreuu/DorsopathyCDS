# Как посмотреть локальную демонстрацию

Это демонстрация проверки условий одной клинической гипотезы у взрослых.
Примеры синтетические; результат не устанавливает диагноз и не показывает
вероятность заболевания.

## Запуск

В терминале выполните:

```sh
cd /Users/andrew/Projects/DorsopathyCDS
PYTHONPATH=src python3 -m dorsopathy_cds serve --port 8765
```

Оставьте процесс работающим и откройте в браузере
[http://127.0.0.1:8765/](http://127.0.0.1:8765/).
Для остановки сервера нажмите `Ctrl+C` в терминале.

## Первый пример и три состояния

1. Откройте страницу: пример **«Все условия выполнены»** уже выбран и проверен.
   Вы увидите **«Гипотеза поддерживается»**: переданные оценки удовлетворяют правилу.
2. В оценке соответствия нейровизуализации клинике выберите **«Не оценено»**
   и повторите проверку. Результат — **«Нужны дополнительные данные»**.
3. Выберите **«Врач указал несоответствие»** и повторите проверку.
   Результат — **«Условия правила не выполнены»**. Это не исключает заболевание.

Форма содержит три врачебные оценки и статус исследования. Она не выполняет
неврологический осмотр и не анализирует снимки: оценки вносит врач, а для
демонстрации их задаёт выбранный пример.

## Что открыть в результате

- Три пункта показывают, какие условия выполнены, не выполнены или неизвестны.
- В раскрытии источника доступны дословный фрагмент, документ и страница.
- Пояснение неизвестного значения показывает, какой факт требуется уточнить.
- Раскрытие «Технический отчёт JSON для разработчика» предназначено для разработчика: там доступны входные факты,
  версии, ссылки на цитаты и подробная трассировка вычисления.

## Остальные примеры

| Пример | Что демонстрирует |
|---|---|
| «Соответствие МРТ клинике не оценено» | Соответствие снимков клинике не оценено |
| «МРТ не соответствует клинической картине» | Указано несоответствие снимков клинике |
| «Исследование не выполнялось» | Исследование явно не выполнялось; проверка соответствия снимков неприменима |
| «Пункт об отсутствии настораживающих признаков не выполнен» | Не выполнена оценка отсутствия настораживающих признаков |

Отсутствие файла не означает, что исследование не выполнялось. Неизвестная
оценка не равна отрицательной. Для последнего примера система показывает
результат ограниченного правила; полный алгоритм срочной маршрутизации
в эту демонстрацию не входит.
