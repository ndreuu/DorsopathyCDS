# Локальные первоисточники

Официальный PDF КР №777 хранится локально как `777_1.pdf` и исключён из Git.
Адрес загрузки, версия, хеш PDF, короткие цитаты и номера страниц находятся
в `src/dorsopathy_cds/catalog/sources.json`.

Для проверки файла: `python3 scripts/verify_sources.py` из корня репозитория.
Проверка хеша подтверждает совпадение с зафиксированным файлом. Она не
проверяет наличие новой редакции рекомендаций и не подтверждает корректность
клинической формализации. При обновлении источника нужны повторная проверка
цитат и врачебная проверка правила.

В метаданных зафиксирован снимок официального рубрикатора на 2026-10-08.
Номер редакции документа — `version: 1`; служебное поле API `ver: 2` не
является номером редакции клинических рекомендаций.
