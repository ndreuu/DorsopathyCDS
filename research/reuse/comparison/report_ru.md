Проверено 09.10.2026 (Europe/Istanbul). Только подбор; код, зависимости и данные не устанавливались. Рекомендация: существующий snapshot + JSON-sidecar с детерминированными правилами; MNE для подтверждённых общих событий, SimpleITK для известного transform, vtk.js при необходимости пространственного просмотра. В [contracts.py](../../../src/dorsopathy_platform/contracts.py) уже есть ModuleResult 1.0, quality/origin, anatomy, acquired_at, coordinate_frame и evidence {artifact_id, selector}. Валидатор проверяет структуру/ссылки, но не тождество пациента, часы или регистрацию. [storage.py](../../../src/dorsopathy_platform/storage.py) фиксирует выбранные result IDs, canonical SHA256 и immutable snapshot; [ArtifactAccess](../../../src/dorsopathy_platform/ports.py) даёт проверенное потоковое чтение/сохранение. В этой ветке отсутствует обещанный T00 frozen ComparisonReport: формы ниже — предложения для согласования, не альтернативная production-схема.

**Связанные данные.** [putEMG, официальный поставщик](https://biolab.put.poznan.pl/putemg-dataset/) — публичная загрузка без заявки, данные CC BY-NC 4.0, scripts MIT. Сочетание: 24 sEMG предплечья + RGB MP4 + depth PNG только для gesture trials; HDF5/CSV содержит Timestamp, VIDEO_STAMP, TRAJ_1. Subject/trial есть в имени, depth timestamp — в time domain trial (ms). Подходит для технической проверки linkage/events/window; TRAJ_GT получен DNN, не клиническая оценка. Нет lumbar MRI, термографии, УЗИ, ANI/PMD. Погрешность clocks и MRI→surface calibration публичным описанием не подтверждены: gates остаются unknown. Чтение: pandas.read_hdf(path); [примеры](https://github.com/biolab-put/putemg_examples).

[BioVid Part C](https://www.nit.ovgu.de/BioVid.html) связывает long frontal video, GSR, ECG, trapezius EMG и labels экспериментальных тепловых стимулов. Это экспериментальная боль, не MRI/lumbar clinical corpus. [Соглашение](https://www.nit.ovgu.de/nit_media/Bilder/Dokumente/BIOVID_Dokumente/BioVid_AgreementPartsABCD.pdf) требует академического подписанта/авторизации, запрещает commercial use/передачу и ограничивает публичный показ; для свободно распространяемого demo не подходит. Actual headers/clock mapping без доступа не проверены. В проверенных кандидатах нет всех целевых сенсоров и поясничной МРТ одного пациента; независимые базы не объединять.

**Вход и evidence.** Отдельный source manifest: {source_id, artifact_id, sha256, subject_namespace, subject_id, session_id, protocol_id, linkage_evidence_refs, acquired_interval, clock_domain, time_unit, sampling_hz, channels:[{name,unit,calibration_ref}], events:[{event_id,onset,duration,pose_id,evidence_ref}], frame:{id,units,axes,origin,spacing,direction}, transform_ref}. Неизвестное — null. Selector: {sample_start,sample_stop,channel_ids,event_id} либо {frame_index,roi_id,frame_id}; причины правил ссылаются на первичные metadata/калибровку.

Transform-sidecar: {from_frame,to_frame,units,axes,matrix_or_field_ref,mapping_direction,method,version,landmark_refs,validation_refs,error_metric,error_unit,error_value,valid_pose,time_interval}. Label lower_back/L4-L5 не registration. Для thermal-image→3D дополнительно нужны camera intrinsics, distortion, extrinsics и соответствующая поза; rigid matrix не заменяет camera calibration.

**Gates и порядок будущей сборки.**

1. Проверить hashes и subject/session linkage по первичным metadata/crosswalk evidence; episode ID и linked=true недостаточны. Затем availability, calibration, quality, protocol, сторона/область/pose.
2. Для event_window потребовать общий clock либо подтверждённые пары sync events. Сохранить offset/drift, anchors, residual/uncertainty и acceptance по протоколу; processing time не использовать. MNE не возвращает audit-sidecar: адаптер сохраняет mapping и исходные sample selectors. Нелинейный drift/dropouts требуют отдельного профиля. Корреляция EMG/EDA не доказывает sync.
3. Для spatial_overlay проверить frame/units/axes и независимую validation transform с погрешностью в пределах заданного протокола. Missing calibration — unknown, доказанный mismatch — incompatible; MRI другой даты остаётся отдельным исследованием.
4. Зафиксировать snapshot ID/hash, manifest/selection hash, rules/version, source refs, availability/quality и пары {comparison_kind,result_ids,status,reasons,evidence_refs,window_ref,transform_ref}. Compatible означает требования **конкретной операции**, недостаток evidence — unknown. Сохранить JSON через ArtifactAccess.add_bytes(..., "application/json", role="derived"), крупные outputs через add_file. T05/T07/T08 читают сохранённую редакцию.

Будущая проверка: связанный trial, shifted event, другой subject, missing calibration, wrong frame и поздний result; старый report сохраняет hash. Не вводить medical coherence-score, диагностическую вероятность, исключение болезни или вывод о симуляции при нормальных/отсутствующих сенсорах.
