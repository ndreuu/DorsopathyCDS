# T12 — reusable thermography: подбор, 2026-10-09

**Минимальный стек: ExifTool + Thermimage, отдельный R-worker.** Импорт → raw matrix → температурная matrix → заданные ROI mean/min/max → left-minus-right delta → heatmap. Обучение, веса и камера для импорта не требуются. Сейчас только подбор: application/common files не изменены, зависимости не установлены. Прочитаны AGENTS.md, T12, brief и ModuleResult 1.0; база `6161304de7c02960fa3d40e681ef612e90cd3e17`.

## Canonical input и ModuleResult 1.0 — предложения

В JSON artifacts: source/hash/license/linkage; vendor/model/lens/firmware/export/FFF/parser versions; raw dtype/endian/shape; converted float64/Cel/validity-mask; **file-specific** Planck/atmospheric constants; emissivity fraction, distance m, reflected/ambient/window Cel, transmission fraction, RH%; exact tags, overrides/provenance; time/zone/frame/protocol/pose/focus/warm-up/acclimatization/airflow/reference calibration/uncertainty. Unknown=null. [QIRT primary paper](https://comum.rcaap.pt/bitstreams/f45e7134-14dc-4c2d-9496-1f58f22fd70c/download) поддерживает необходимость acquisition metadata; это не готовый медицинский protocol.

Matrix `[row_y,column_x]`, zero-based thermal pixel centers, top-left, x-right/y-down; display transforms отдельно. ROI/mask/author/region/anatomical side задаются явно; image-left не anatomical-left. `mean=sum(validT)/N`; min/max той же mask, unit Cel. **delta=mean(left)−mean(right), unit K**; pair compatibility compatible/incompatible/unknown.

Предлагаемые concepts: `thermography.roi.mean_temperature`, `.min_temperature`, `.max_temperature`, `thermography.roi_pair.mean_temperature_difference`. Согласовать T00/T08. Реальный origin automatically_measured; synthetic_demo для fixture; model=null; method `flir-rjpeg-planck.roi-stats.v1`; acquired_at source timezone-aware или null. Evidence: original+frame, matrix+ROI, analysis+statistic/pair, heatmap+scale. Selector пример `{"frame_index":0,"roi_id":"roi_left","statistic":"mean"}`. Artifact IDs/hash/size/media_type/source-or-derived обязательны; Observation не расширять.

## QC/gates

Проверять bounded records/dimensions/endian; reject missing radiometry; не использовать чужие camera defaults. Проверять correction domains/log/finite/saturation/invalid pixels; неизвестные физические условия → unknown/unreliable или not_assessed. ROI empty/outside/недостаточное coverage и несовместимая pair → partial; весь input без radiometry → failed без observations. Missing не zero/false. Same session/view/geometry/time/protocol/corrections нужны для pair.

Capture требует конкретную radiometric camera/SDK/reference. [DJI TSDK 1.8](https://www.dji.com/downloads/softwares/dji-thermal-sdk) — Windows/Linux native RJPEG; License.txt/binary не проверены, macOS не заявлен. Unsupported FLIR ATS/CSQ/SEQ требуют verified importer/SDK. Open lower-back paired skin/reference corpus не найден. Runtime, PNG byte-swap, accuracy и viewer selectors остаются future acceptance; отсутствие e2e freeze — интеграционная задача, не blocker исследования.

Synthetic-only arithmetic: `[[30,31,32,33],[34,35,36,37]] Cel`; masks columns 0–1 / 2–3: means 32.5/34.5, delta −2 K. Не доказывает camera/calibration. **Температура не устанавливает воспаление, источник/отсутствие боли, диагноз или исключение болезни.** Проверки сдачи: JSON parse, diff whitespace, ownership; behavior tests не нужны для document-only change.
