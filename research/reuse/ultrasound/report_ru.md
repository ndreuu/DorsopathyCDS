# T14: повторное использование для УЗИ

Проверено 2026-10-09. Исследование первичных источников; без установки, реализации, скачивания корпусов и runtime-проверки. Первый endpoint: толщина/расстояние между двумя ручными границами мышцы (mm), затем площадь плоского замкнутого контура (mm2). Эти измерения не устанавливают воспаление, патологический очаг или причину боли; эхогенность не является жировой фракцией.

## Выбор инструментов

Минимально рекомендую **pydicom + ImageJ1**: импорт metadata/кадра и готовая ручная разметка с экспортом. Будущему адаптеру нужны проверка calibration и provenance. 3D Slicer — альтернатива единого рабочего места, при supported export. Веса, обучение и прибор не нужны для обработки записанного кадра; захват остаётся отдельным gate.

| Кандидат | Реально доступные entrypoints и exports | Лицензия и ограничения |
|---|---|---|
| **pydicom** | `pydicom.dcmread(path, stop_before_pixels=True)`; `ds.SequenceOfUltrasoundRegions`; `pydicom.pixels.pixel_array(path, index=frame)` → NumPy выбранного кадра. | [MIT, private dictionaries с BSD notice](https://github.com/pydicom/pydicom/blob/main/LICENSE); [API 3.0.2](https://pydicom.github.io/pydicom/stable/reference/generated/pydicom.pixels.pixel_array.html). ## Геометрия

[DICOM US Region Calibration](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.8.5.5.html): region bounds, spatial format/data type, PhysicalUnitsX/Y, PhysicalDeltaX/Y. Первый профиль ограничить одной однозначной 2D B-mode tissue region, обе units=3, конечные ненулевые deltas; `sx=10*abs(deltaX)`, `sy=10*abs(deltaY)` mm/pixel. Расстояние `sqrt((dx*sx)^2+(dy*sy)^2)`; simple polygon shoelace area × `sx*sy`. Это ограничение профиля, не универсальная поддержка УЗИ. Cartesian scan-converted sector допустим с документированной geometry; raw polar/3D/proprietary, M-mode/Doppler и conflicting overlaps не оцениваются. PNG требует scale JSON: X/Y, bounds, источник/автор/дата, crop/resize transform. Вертикальный ruler без подтверждённого aspect не устанавливает X-scale.

## Открытые данные

1. **LUMINOUS — прямое анатомическое соответствие.** [IMPACT provider](https://users.encs.concordia.ca/~impact/luminous-database/): LM L5, 109 молодых спортсменов, prone/standing, TIFF B-mode и ручные binary masks; Download ведёт в Dropbox. GE LOGIQ e, depth 8 cm. [Первичная статья](https://link.springer.com/article/10.1186/s12891-020-03679-3): CC BY 4.0 статьи, CC0 clause для данных статьи. Отдельная лицензия внешнего архива не указана, автоматически переносить её нельзя. TIFF headers/calibration и README не проверены; 8 cm depth не заменяет per-image scale. Подходит для ручной CSA, не готовый thickness reference и не репрезентативная выборка всех пациентов с болью.
2. **BrEaST/BREAST-LESIONS-USG — generic importer.** [TCIA provider](https://www.cancerimagingarchive.net/collection/breast-lesions-usg/) в поисковой выдаче: PNG+ZIP images/segmentations, CC BY 4.0; direct fetch вернул 500. Реальные breast US, не lumbar endpoint. Архив/scale не проверены: просмотр/контуры/evidence, метрическая приёмка закрыта.
3. **Cross Fit Tsartsapakis 2023.** [Mendeley](https://data.mendeley.com/datasets/4sx58vt8v9/1), CC BY 4.0: SPSS относительной thickness LM/TrA/IO и EMG. Это числовой экспорт для изучения протокола, не изображения/geometry test.

## ModuleResult 1.0 и data gates

Предложить владельцу concepts `ultrasound.muscle_thickness`/`ultrasound.muscle_area`, units mm/mm2. Для программного вычисления по ручным точкам: `origin=automatically_measured`, `method=manual_landmarks_calibrated_2d_distance` либо `manual_contour_calibrated_2d_area`, `model=null`; авторство разметки обязательно в evidence JSON. Неизвестное `acquired_at=null`. Структура/сторона/уровень, pose/protocol, качество, SOP/frame, calibration и pixel↔world transform — sidecar, без новых Observation fields. Source, annotation JSON/ROI, calibration JSON, overlay PNG → ArtifactRef (`artifact_id/storage_key/sha256/media_type/size_bytes/role`), связанные evidence_refs с frame/coordinate selector. Проверка: `validate_result(result, request)` из существующего contracts.py.

До real metric результата: разрешённый малый оригинальный DICOM с US tags и scanner reference measurement либо PNG/TIFF с проверенными X/Y scales; право использования LUMINOUS архива; actual header/bounds/decoder/frame/overlay round-trip; ручные границы с автором, pose/side/level/QC. Reject: NaN, дубликаты, выход из bounds, самопересечение/неплоский contour, неоднозначные units. Без scale доступны просмотр/разметка, но value=null и assessment_status=not_assessed с причиной. Synthetic fixture с анизотропным scale проверяет математику и overlay, маркируется synthetic_demo и не закрывает real-export gate.
